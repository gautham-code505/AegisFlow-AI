# Test Videos

This directory is used for storing test videos for AegisFlow AI's Vision pipeline.

## Usage
When using the `/api/v1/video/upload` endpoint, videos will be uploaded and temporarily stored here (e.g. `data/videos/temp_upload.mp4`) during processing. The output annotated video will be saved here as well (e.g. `data/videos/output.mp4`).

**Note:** Do not commit large copyrighted video files to this directory.
